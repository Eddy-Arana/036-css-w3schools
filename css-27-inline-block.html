Lección 27 - CSS display: inline-block

display: inline

Caja 1 Caja 2 Caja 3

Los elementos inline permanecen en la misma línea, pero no respetan correctamente propiedades como width y height.

display: inline-block

Caja 1 Caja 2 Caja 3

Los elementos inline-block permanecen en la misma línea, pero permiten definir ancho, alto, márgenes y relleno como un elemento de bloque.

display: block

Caja 1 Caja 2 Caja 3

Los elementos con display: block ocupan todo el ancho disponible y comienzan en una nueva línea.
