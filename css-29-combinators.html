Lección 29 - CSS Combinators

1. Descendant Combinator (espacio)

Selecciona todos los elementos descendientes.

Este párrafo es descendiente del div.

Este también es descendiente.

2. Child Combinator (>)

Solo selecciona los hijos directos.

Hijo directo (seleccionado).

No es hijo directo (no seleccionado).

3. Next Sibling Combinator (+)

Selecciona únicamente el primer hermano siguiente.

Elemento DIV

Primer párrafo (seleccionado).

Segundo párrafo (no seleccionado).

4. Subsequent Sibling Combinator (~)

Selecciona todos los hermanos siguientes.

Elemento DIV

Primer párrafo (seleccionado).

Segundo párrafo (seleccionado).

Tercer párrafo (seleccionado).

Resumen

  • Espacio ( ) Selecciona todos los descendientes.
  • > Selecciona únicamente hijos directos.
  • + Selecciona el hermano inmediato.
  • ~ Selecciona todos los hermanos siguientes.
