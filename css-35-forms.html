Resumen

  • width: controla el ancho del campo.
  • padding: agrega espacio interno.
  • margin: agrega espacio externo.
  • border: personaliza el borde.
  • border-radius: redondea las esquinas.
  • background-color: cambia el fondo.
  • :focus: aplica estilos al seleccionar un campo.
  • textarea: permite escribir varias líneas.
  • select: personaliza listas desplegables.
  • Buttons: permite diseñar botones del formulario.
  • Media Query: adapta el formulario a pantallas pequeñas.
