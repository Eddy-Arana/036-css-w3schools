Resumen

  • Dropdown: muestra contenido oculto cuando el usuario pasa el cursor o hace clic.
  • position: relative: sirve como referencia para el contenido desplegable.
  • position: absolute: coloca el contenido debajo del elemento principal.
  • display: none: mantiene oculto el contenido.
  • :hover: permite mostrar el contenido al pasar el mouse.
  • box-shadow: agrega una sombra para dar apariencia de menú flotante.
