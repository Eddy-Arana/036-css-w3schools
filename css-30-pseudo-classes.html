Resumen

  • :hover Aplica estilos al pasar el cursor.
  • :focus Aplica estilos cuando un elemento recibe el foco.
  • :link Enlace sin visitar.
  • :visited Enlace visitado.
  • :active Enlace mientras se hace clic.
  • :first-child Primer hijo.
  • :last-child Último hijo.
  • :nth-child() Selecciona un hijo específico.
  • :lang() Selecciona elementos según el idioma.
